# Zerodha Clone

A front-end clone of the [Zerodha](https://zerodha.com) website built using HTML and CSS.

## About

This project is a static single-page clone of Zerodha's website. I built this to practice my HTML and CSS skills — focusing on layout, styling, and making a real-world website look-alike from scratch.

## Pages / Sections

- **Home** — hero section with stats
- **Signup** — mobile number form
- **About** — company info and team
- **Products** — Kite, Coin, Varsity and more
- **Pricing** — brokerage charges table
- **Support** — help categories and search

## Tech Used

- HTML
- CSS

## How to Run

Just open `index.html` in your browser. No installation needed.
